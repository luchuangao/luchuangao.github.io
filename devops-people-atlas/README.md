# 工程人物志 · Dev & Ops Atlas

公开访问：https://luchuangao.github.io/devops-people-atlas/

本目录是独立的静态网站，包含 36 位开发与运维代表人物，涵盖 6 个方向。提供 X、个人网站、GitHub、贡献简介、主题标签、代表作品、学习入口、资料来源与核实日期，并支持搜索、筛选、收藏和 JSON 导出。

## 预览与维护

无需安装依赖或构建。在仓库根目录运行 `python3 -m http.server 4173`，访问 `http://localhost:4173/devops-people-atlas/`。

人物资料保存在 `people.json`。未确认的账号链接为 `null`；个人账号与项目、组织链接分别展示。首版核实日期为 2026-10-10，这是一份编辑精选目录，并非完整排名；链接不会自动更新。Joe Beda 的个人网站在本轮核查时出现证书问题，已在界面中标注。

所有页面、样式、脚本和数据均放在本目录，通过相对路径引用。发布沿用仓库现有 GitHub Pages 配置；本次新增不修改首页、其他目录或托管设置。
