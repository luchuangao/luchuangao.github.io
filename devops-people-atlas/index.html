ABOUT THIS FIELD GUIDE

一份可追溯的工程人物目录

首版精选对编程语言、开源软件、Web 开发、云基础设施、软件工程或运维实践有代表性贡献的人物。它是学习导航，不是影响力排行榜，也无法覆盖这一领域的所有重要人物。

这里收录什么

个人账号与网站、主要贡献、代表项目或著作、内容语言，以及编辑推荐的学习入口。项目链接可能指向组织仓库；它们会与个人 GitHub 账号分别展示。

如何核实

本轮核实日期为 2026-10-10。优先采用本人官网、官网互链及可确认身份的 GitHub 档案。每个人物详情均列出来源。未找到可靠依据的链接标记为“未确认”；这不表示本人没有账号。

核实指身份和公开链接的交叉确认，不意味着 X 登录页、每个地区的可访问性或未来链接状态均已保证。部分人物主要使用其他平台，详情中会注明。

如何使用

输入姓名、技术或作品名，按工程方向及内容语言筛选；点击“人物详情”查看代表作品、学习入口和来源。收藏只保存在当前浏览器。下载资料可获得全部收录数据及来源，便于自行维护。

简介为中文编辑整理，推荐学习入口属于编辑选择。资料按本轮核实状态呈现，不会自动更新。
